# Kenara Visuals

Landing page SPA untuk Wedding & Event Content Creator di Kendari dan Unaaha.

## Menjalankan project

```bash
npm install
npm run dev
```

Build production dan pemeriksaan kode:

```bash
npm run build
npm run lint
```

## Mengganti konten

Konten bisnis berada di `src/config`:

- `contact.ts` — WhatsApp dan Instagram
- `services.ts` — jenis layanan dan pilihan form
- `packages.ts` — paket, harga, dan deliverables
- `portfolio.ts` — gambar dan label portfolio
- `site.ts` — identitas dan cakupan area

Visual portfolio berada di `public/assets`. Harga dan visual saat ini merupakan konten demo hingga data final Kenara tersedia.
